# PUBLISHER CONTENT POLICY
#
# Search engine crawling and indexing: ALLOWED
# AI search and generative search: ALLOWED
# Real-time AI retrieval and grounding: ALLOWED
# Retrieval-augmented generation (RAG): ALLOWED
# Citation and reference use: ALLOWED
# User-requested retrieval: ALLOWED

# Foundation-model training and fine-tuning: NOT ALLOWED

# retrieval/grounding and training and access is intentionally permitted below.

# Restoring Democracy's Promise expressly welcomes indexing, citation,
# linking, summarization for search/reference purposes, and real-time
# retrieval that directs users to the original reporting.

# Copyright and related rights are reserved for uses beyond those permitted
# by these signals.
