How it works

Projects

Every bid you have loaded, with its countdown and open items. Pick one above or create a new one.

Workflow

  1. Documents. Drop the project manual, electrical sheets and every addendum as PDF (text is extracted locally) or paste text. Each file is hashed for the source map.
  2. Questions. The engine pre-fills what it found (bid date, question deadline, addenda, voltage, funding clauses) and asks only what the documents leave open.
  3. Takeoff. Line items split by who quotes them: electrical distributor, mechanical supplier, systems integrator, other packages, contractor-carried material, and ambiguous items that need an RFI. Edit quantities and channels inline.
  4. RFIs. Ready-to-send questions ranked by pricing impact, each with the basis the bid carries if unanswered. Track sent and answered dates.
  5. Schedule. Milestones backed off the bid date. Export to your calendar (.ics with alarms) and turn on browser reminders.
  6. Exports. Excel workbook, quote requests per channel, RFI log, takeoff report, and a JSON backup of the whole project.
  7. Claude review (optional). Send the relevant pages to Claude with your own API key for a second, cited opinion you can merge line by line.

      How reminders reach you

      Calendar file (reliable). Import the .ics into Google Calendar, Outlook or Apple Calendar. Every milestone becomes an event with alarms, and the RFI-send event lists the open RFIs in its description. Re-download after changing the bid date or answers; the events keep the same IDs so imports update in place.

      Browser notifications (while open). With notifications enabled, this page checks every minute and raises a notification for milestones due within 24 hours or overdue, once per milestone per day. A static site cannot send email or push when the tab is closed, so use the calendar file as the primary reminder.
