    What this count covers

    One benefit code. These reports are filtered to benefit code 23, “Professional License.” The agency filter on their face is set to ALL — it is the benefit code that limits them. USCIS told RDP that “Professional License” is a standard SAVE benefit category used by many registered user agencies. An Iowa account operating under a different benefit code would not appear in these reports at all.

    Benefit code 23 — professional licensing16,457

    The Iowa Department of Transportation separately told RDP that it uses SAVE when people apply for driver's licenses, through a different federally required pathway that does not run through DIAL.

    Additional verifications are separate. 98 across the period, counted in their own column. The two figures are never added.

    Third-step verifications are not reported at all. USCIS told RDP that third-step verification refers to manual review and retains the same benefit type as the original case. These reports carry no third-step column, so 16,457 is a floor on transactions, never a ceiling.

    August is partial. The report was prepared Aug. 12, 2026. USCIS confirmed that a month-end report generated mid-month contains data through the day before it is run, so this report covers transactions through Aug. 11.

    SAVE returns a verification response.

    The licensing agency submits the applicant’s information to SAVE. SAVE checks it against federal immigration records and returns a verification response. Some checks resolve immediately. Others require additional verification.

    Additional verification

    Additional verification is the follow-up step when a case does not resolve immediately.

    The question stays open.

    The template is written for the expiry.

    DIAL's staff template addresses licensees whose work authorization or admission period is scheduled to expire. It has two selectable paragraphs — one for when that date falls before the license expires, one for when it falls after — and both carry the same warning.

    A staff note on the same page contemplates running another SAVE check after that date. The note is marked “DO NOT USE THIS YET UNTIL LEGAL APPROVES WORDING.”

    Outline = documented procedure, not an observed event.

    The paragraph DIAL sends

    “If your current immigration status is not maintained, your license status may be affected, including revocation of your license.”

    DIAL staff template, released Aug. 20, 2026 under Iowa Code chapter 22. One paragraph of the template was withheld as still under legal review.

    This is a stated consequence in a notice template — a procedure and a possibility. No record produced so far shows any Iowa professional license denied, suspended, or revoked because of a SAVE result.

    What the records don't show

    No record produced so far shows any Iowa professional license denied, suspended, or revoked because of a SAVE result.

    Iowa's own sworn filing described more than 350 licenses within DIAL that could not be verified and therefore could not be issued — a stall, not a revocation. This is Batch 001 of a rolling production, and the absence of a produced record is not proof that nothing happened.

    What USCIS confirmed

    In its Sept. 4, 2026 response to RDP’s questions, USCIS confirmed:

    • One initial verification is one transaction.
    • An agency can submit another transaction for the same person.
    • “Professional License” is a standard SAVE benefit category used by many registered user agencies.
    • The Dec. 23, 2025 DIAL–USCIS memorandum of agreement remains in effect.
    • DIAL continues to retain SAVE access for professional-licensing verification.

    Right of response

    DIAL and USCIS were sent detailed questions on Aug. 31, 2026, with a response requested by Sept. 4. USCIS responded on Sept. 4; its answers are reflected in this exhibit. DIAL's response was still pending when this version was published. This exhibit will be updated if DIAL responds.

    This is not a real person's case

    No case-level records have been released in this production. RDP has not seen any individual's SAVE case.

    This sequence is assembled from Iowa's executed agreements, its own staff templates, the monthly transaction reports DHS prepared and Iowa released, and a sworn declaration filed in federal court. Every step shown is documented as procedure. None of it is a record of a particular person.

    The board field reproduces DIAL's own placeholder text. No board is named, no dates are given, and there is no case number — because the production contains nothing that would supply them.

    People: not established

    The reports count transactions. They do not identify unique applicants, so they cannot establish how many people were checked.

    USCIS told RDP that an initial verification is one transaction, and that an agency can submit another transaction for the same person. Nothing in the reports maps the transactions to unique applicants.

    Cases: a different unit

    Aaron Baack, DIAL's interim director, swore on July 1, 2026 that the State had “submitted more than 8,150 cases” through the SAVE system since December 2025.Sworn testimony — not established by records

    Adding the released reports for December through June — the period ending the day before he signed — gives 8,174 initial verifications. That is a shorter span than the 16,457 above, which runs through the August report.

    The two figures count differently defined units. They corroborate each other. They are not the same number.

    Transactions: documented

    This is what the reports count: initial verifications, generated by the Department of Homeland Security's SAVE program and released by Iowa under its open-records law. USCIS confirmed that each initial verification is one transaction.

    Seven monthly reports—December through June—were independently pulled twice, on July 13 and Aug. 12, 2026. Every month matches.

    USCIS did not answer whether testing, training, development or other non-production activity can appear in these benefit-code reports. That question is open.
